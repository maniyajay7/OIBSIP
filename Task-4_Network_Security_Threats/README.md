# Task 4: Network Security Threats — Research Report

## 📌 Objective
Research and document the most critical network security threats, including how they work, real-world examples, and recommended countermeasures.

## 📄 Report Contents

The report covers **8 major network security threats** in detail:

| # | Threat | Description |
|---|--------|-------------|
| 1 | **Malware** | Viruses, worms, trojans, ransomware, spyware — with WannaCry case study |
| 2 | **Phishing** | Email, spear, whaling, smishing, vishing — with Google/Facebook BEC case study |
| 3 | **Man-in-the-Middle** | ARP spoofing, DNS spoofing, SSL stripping, Evil Twin attacks |
| 4 | **DDoS** | Volumetric, protocol, and application layer attacks — with Mirai botnet case study |
| 5 | **SQL Injection** | In-band, blind, out-of-band injection — with Heartland breach case study |
| 6 | **DNS Attacks** | DNS spoofing, tunneling, hijacking, amplification |
| 7 | **Insider Threats** | Malicious, negligent, and compromised insiders |
| 8 | **Zero-Day Exploits** | Unknown vulnerabilities with no patch — with Log4Shell case study |

### Additional Sections
- **Threat Landscape Summary** — Comparison table of all threats by attack vector, impact, and difficulty
- **Defense-in-Depth Strategy** — Multi-layered security model from physical to user security
- **Conclusion & References** — OWASP, MITRE ATT&CK, NIST Framework, CISA

## 🔑 Key Takeaways
- No single security measure can stop all threats — use defense-in-depth
- Most breaches exploit known vulnerabilities — timely patching is critical
- Human error is the weakest link — employee training is essential
- Monitoring and incident response are just as important as prevention
